# Tmux Desk 会话 Tag 与聚合页签设计

## 目标

为每个 tmux 会话支持零到多个本地 Tag，并让 Tag 成为左侧功能栏中的工作区入口。用户选择某个 Tag 后，中间会话列表收起，属于该 Tag 的会话像浏览器页签一样聚合在终端上方；每个会话在同一 Tag 内只出现一次。选择“全部”时恢复现有中间会话列表。

## 已确认的交互

### 视图层级

- “全部”是唯一保留中间会话列表的视图，继续提供搜索、刷新、新建和会话行操作。
- “收藏”与普通 Tag 都是紧凑工作区：中间会话列表收起，主工作区扩展到左侧功能栏旁边。
- 普通 Tag 视图顶部显示该 Tag 下的会话页签；收藏视图以同样方式显示收藏会话页签。
- 页签只代表 tmux 会话。现有 `2 claude.exe`、`3 server` 一类 tmux window 页签行从界面移除。
- 多 pane/window 的定位继续通过工作区右上角 pane 选择器与 `⌘1…9` 快捷键完成，不删除底层 tmux window/pane 控制能力。

### Tag 导航

- 左侧功能栏在“全部/收藏”和底部主题/设置之间显示可滚动的 Tag 列表与新建按钮。
- Tag 按创建顺序展示；按钮使用稳定颜色和名称首字符，在 tooltip/无障碍名称中展示完整名称与会话数。
- 点击 Tag 进入紧凑工作区；当前 Tag 有明确选中态。
- 新建按钮打开 Tag 编辑弹窗。设置页提供 Tag 列表，可执行新建、重命名和删除。
- 删除 Tag 只删除分类及会话关联，不关闭任何 tmux 会话；删除当前 Tag 后回到“全部”。

### 会话关联

- 一个会话可以属于多个 Tag。
- 会话右侧 `…` 菜单和工作区会话菜单提供“管理 Tag…”入口。
- “管理 Tag”弹窗显示全部 Tag 的多选项，保存后一次性替换该会话的 Tag 集合。
- 归一化层对 Tag id 去重，因此同一会话在一个 Tag 内不会重复。
- “全部”视图的会话行用小色点展示已关联 Tag，悬停可查看名称。
- 在普通 Tag 视图中创建新会话时，自动关联当前 Tag；复制会话时继承源会话的全部 Tag。

## 本地数据模型

继续使用 Electron `userData/preferences.json`，新增两个字段：

```json
{
  "tags": [
    { "id": "tag-…", "name": "DMS 渠道", "color": "blue" }
  ],
  "sessionTags": {
    "channel-biz-ds": ["tag-…"]
  }
}
```

- `tags`：有序 Tag 定义。`id` 为主进程生成的稳定标识；名称去首尾空白、非空、最长 40 个 Unicode 字符且不重名；颜色必须来自内置色板。
- `sessionTags`：以 tmux session 名称为键，以 Tag id 去重数组为值。不存在的 Tag id、空 session 名和空数组在归一化时移除。
- 选择名称作为会话关联键，是因为 tmux `$N` id 会在 server 重启后变化；这与现有收藏模型一致。
- 会话重命名时同步迁移 `favorites`、`lastSession` 和 `sessionTags`，合并目标键并去重。
- 应用内关闭会话时删除其 `sessionTags`；外部关闭留下的关联允许同名会话重新出现后恢复分类。
- 损坏或旧版偏好文件继续归一化到安全默认值，新增字段默认为空，不需要一次性迁移脚本。

## 模块边界

### 主进程与 IPC

- `PreferencesStore` 负责 Tag 定义、会话关联、重命名迁移与原子写入。
- 新增严格白名单 IPC：创建、重命名、删除 Tag，以及替换指定会话的 Tag 集合。
- renderer 不直接写任意偏好字段；Tag 名、id、颜色、会话名和数组长度均在 IPC 边界校验。
- 删除、重命名 Tag 与会话关联变更不调用 tmux，不会影响正在运行的进程。

### Renderer

- 应用状态使用 `view = { kind: "all" | "favorites" | "tag", tagId?: string }` 代替单一 `favoritesOnly` 布尔值。
- `sessionsForCurrentView()` 统一计算紧凑视图页签，按最近活跃时间排序并去重。
- 切换到紧凑视图时，若当前会话仍属于该视图则保持连接；否则选择首个会话；空视图则安全 detach 并显示专用空状态。
- `renderSessionTabs()` 只在收藏或 Tag 视图渲染会话页签；“全部”视图不显示该行。
- `renderDetail()` 只维护 pane 选择器，不再创建 tmux window 标签 DOM。
- 每两秒刷新 tmux 元数据时保留当前视图；会话被外部关闭后选择该视图中的下一个可用会话，或进入空状态。

## 空状态与错误处理

- 无 Tag：功能栏只显示新建按钮；“管理 Tag”弹窗提供新建引导。
- Tag 无存活会话：显示 Tag 名称、“这个 Tag 还没有会话”和“返回全部”，不启动 PTY。
- 收藏为空：显示“还没有收藏会话”和“返回全部”。
- 保存失败：保留弹窗与用户选择，显示非阻断错误，不乐观覆盖已加载偏好。
- Tag 名重名、过长或非法 id/颜色：在主进程拒绝并显示简短中文错误。
- 删除当前正在查看的 Tag：完成持久化后切回“全部”，当前终端连接保持不变并重新显示会话列表。

## 测试与验收

### 自动化

- 偏好归一化：多个 Tag、无效定义、重复名称、重复/失效关联与旧版配置回退。
- `PreferencesStore`：创建、重命名、删除 Tag，替换会话 Tag，复制关联，重命名会话迁移和关闭清理。
- IPC：所有新通道均在白名单内；Tag 名、id、颜色、会话名和 Tag id 数组拒绝畸形输入。
- 会话模型：普通 Tag、收藏紧凑视图按活动时间排序、一个 Tag 内去重、空视图和多 Tag 交叉归类。
- Renderer 构建成功，现有会话、终端、文件浏览器、Shift+Enter 和主题测试不回退。

### 端到端验收

1. 从左侧 `+` 创建至少两个 Tag；重启应用后仍存在。
2. 为同一会话勾选两个 Tag，在两个 Tag 视图中各出现一次。
3. 进入 Tag 后中间会话列表消失，主工作区扩宽，顶部只有一层会话页签。
4. 点击同 Tag 页签可切换真实 tmux attach，后台会话不被关闭。
5. 回到“全部”后中间会话列表恢复；搜索、新建和行菜单继续工作。
6. 收藏视图也使用紧凑页签布局。
7. 重命名会话后 Tag 关联保留；复制会话继承 Tag；应用内关闭会话清除关联。
8. 重命名或删除 Tag 不影响 tmux 会话；删除当前 Tag 自动回到“全部”。
9. pane 选择器和 `⌘1…9` 仍可切换 window/pane，界面不再出现 tmux window 页签行。
10. `npm test`、`npm run test:integration`、`npm run build` 和当前 Mac 架构的 DMG/zip 打包全部成功。

## 手机 / 其他设备兼容补充（2026-07-11）

### 共享数据与服务边界

- Web 服务与桌面端读取同一份 `preferences.json`。桌面内嵌服务直接复用当前 `PreferencesStore`；命令行守护进程按 Electron 的平台目录规则定位同一文件，并允许用 `TMUX_DESK_PREFERENCES_FILE` 显式覆盖。
- `GET /api/sessions` 在原有会话列表外返回经过归一化的 `tags`、`favorites` 和 `sessionTags`，不暴露主题、窗口尺寸或任意偏好字段。
- `POST /api/session-tags` 只允许为当前存活且非 `_web_*` 的会话替换 Tag id 集合；复用桌面相同的会话名、Tag id、数量上限和去重校验，并继续受 URL token 保护。
- 同一个 `PreferencesStore` 内的读改写操作串行执行，避免桌面与多个已连接设备同时修改不同会话时互相覆盖。

### 移动会话工作区

- 会话列表顶部使用可横向滚动、44px 触控目标的“全部 / 收藏 / Tag”筛选条；Tag 按桌面顺序、颜色与实时存活会话数显示。
- “全部”显示每个存活会话一次；收藏和 Tag 复用共享选择器，按活跃时间排序并按会话名去重。当前 Tag 被桌面端删除后，下一次刷新自动回到“全部”。
- 会话卡展示它关联的全部 Tag；“管理 Tag”按钮打开底部面板，复选后一次性保存完整集合。点击管理按钮不会误触进入终端。
- 手机终端保持独立派生 tmux 会话与底部辅助键。原来的第二层 tmux window 胶囊页签改为顶部单个窗口选择器，避免与会话 Tag 视图形成两层页签，同时保留触屏切换 window 的能力。

### 移动布局与失败行为

- 支持 iOS/Android 浏览器和添加到主屏幕模式：使用 `100dvh`（含旧浏览器回退）、`visualViewport` 初始/resize/scroll 同步、刘海安全区和横竖屏重新 fit。
- 所有筛选、会话操作、窗口选择和弹层按钮保持至少 44px 触控高度；底部面板在窄屏上固定到底部，在横屏或大屏仍限制高度并内部滚动。
- Tag 保存失败时保留面板与勾选状态并显示错误；刷新失败不清空上一次成功加载的会话；WebSocket 断线继续使用现有重连提示。
- 移动端不提供 Tag 新建、重命名或删除，避免把设置管理面板复制到小屏；这些定义仍由桌面端管理，移动端只筛选和修改会话关联。

### 补充验收

11. 手机列表能在“全部 / 收藏 / 任一 Tag”间切换；一个会话属于多个 Tag 时可在多个视图出现，但在同一视图只出现一次。
12. 手机修改一个会话的多个 Tag 后，桌面端下一次刷新读取到相同关联；多个设备连续修改不同会话不会丢失前一个结果。
13. 手机终端顶部不再出现 `2:claude / 3:server` 式第二排页签；窗口选择器仍能切换真实 tmux window。
14. 375px 竖屏、横屏和虚拟键盘弹出时，筛选条、终端、辅助键与底部面板均无横向溢出或不可点击区域。

## 非目标

- 不实现 Tag 嵌套、云同步、拖拽归类、自动规则、跨 Mac 同步或与 Termius 数据互通。
- 不改变 tmux server、session/window/pane 的生命周期语义。
- 不把终端内容、命令或 Tag 数据发送给第三方、遥测或云服务；只有用户主动启动本机 Web 服务后，数据才在这台 Mac 与持有 token 的访问设备之间传输。
- 不在移动端创建、重命名或删除 Tag；只允许在已认证的本机 Web 服务上读取分类并修改存活会话的关联。
